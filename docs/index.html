Overview

Lane is a structured development workflow that coordinates specialized AI agents through distinct phases. Inspired by BMAD methodology and Speckit's spec-driven approach.

📋

Phase-Based

Clear 4-phase structure: Analysis → Planning → Implementation → Delivery. Each phase has specialized agents.

🎯

Specialized Agents

9 distinct agents with specific roles, from Analyst to Documenter. Each expert in their domain.

🔄

Smart Routing

Automatic workflow selection based on task type: Quick Flow for bugs, Full BMAD for features, Enterprise for systems.

🔌

MCP Pre-Configured

4 essential services ready out-of-the-box: Context7, Figma, Playwright, and Sequential Thinking. No setup required!

Workflow Types

⚡ Quick Flow ~5 min

For bug fixes and small changes

  • Developer fixes the issue
  • Tester validates the fix
  • Deployer ships the hotfix

🔄 Full BMAD ~15 min

For features and components

  • Architect designs the solution
  • Designer creates the UI
  • Developer implements
  • Full testing and delivery

🏢 Enterprise ~30 min

For systems and architecture

  • Full analysis phase
  • Comprehensive planning
  • Iterative implementation
  • Complete documentation

Commands

Control the workflow with simple slash commands.

/work-ticket "task"

Smart routing - automatically selects the best workflow based on your task description.

/agent [name]

Activate a specific agent. Example: /agent developer

/phase [1-4]

Navigate to a specific phase. Example: /phase 2 for Planning.

/progress

View current workflow status, completed work, and next steps.

/analyze "task"

Start with Analysis phase - research and requirements gathering.

/plan "task"

Start with Planning phase - architecture and design.

/implement "task"

Start with Implementation phase - code and testing.

/deliver "task"

Start with Delivery phase - deployment and documentation.

Pre-Configured MCP Services

Four powerful Model Context Protocol services ready to use out-of-the-box. No additional configuration required!

📚 Context7

Up-to-date documentation and code examples

  • Latest framework docs (React, Vue, Next.js, etc.)
  • API references and guides
  • Best practices and patterns
  • Real-world code examples

🎨 Figma

Design integration via SSE (Server-Sent Events)

  • Review designs in real-time
  • Extract component specifications
  • Generate code from designs
  • Design token extraction

🎭 Playwright

Browser automation and testing

  • End-to-end testing
  • Browser automation workflows
  • Screenshots and snapshots
  • Cross-browser testing

🧠 Sequential Thinking

Advanced reasoning and problem-solving

  • Break down complex problems
  • Multi-step analysis
  • Iterative planning
  • Hypothesis generation and verification

MCP Configuration

All services are pre-configured in .mcp.json. Just clone and run!

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    },
    "figma": {
      "type": "sse",
      "url": "http://127.0.0.1:3845/sse"
    },
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"],
      "env": {
        "DEFAULT_MINIMUM_TOKENS": "6000"
      }
    },
    "sequential-thinking": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sequential-thinking"]
    }
  }
}

Quick Start

Get started with Lane in under 2 minutes. All MCP services are pre-configured!

Setup in 3 Steps

# 1. Clone repository
git clone https://github.com/mazaia/lane.git
cd lane

# 2. Run setup (creates workspace structure)
./scripts/setup

# 3. Start working - MCP services are ready!
/work-ticket "Your task here"

Example Workflows

# Fix a bug (Quick Flow ~5 min)
/work-ticket "Fix login redirect issue"

# Build a feature (Full BMAD ~15 min)
/work-ticket "Add dark mode toggle"

# Design a system (Enterprise ~30 min)
/work-ticket "Build payment processing system"

# Or jump directly to a phase
/phase 3
/agent developer

# Check progress anytime
/progress

# View MCP configuration details
./scripts/setup --info
