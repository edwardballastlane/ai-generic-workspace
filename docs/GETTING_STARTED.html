Environment 1: Claude Code CLI (Terminal)

Setup Steps

1

Install Claude Code CLI

npm install -g @anthropic-ai/claude-code
2

Clone the workspace

git clone https://github.com/mazaia/lane.git
cd lane
3

Run setup

./scripts/setup
4

Start Claude

claude
5

You're ready! Start a workflow

/work-ticket "Your first task"

Terminal Tips

Environment 2: Cursor IDE

Install Cursor IDE

2

3

Check status bar shows MCP services connected

4

Open Cursor Chat

Mac: Cmd+L
Windows: Ctrl+L

5

Start Working

/work-ticket "Your first task"

Cursor Keyboard Shortcuts

Shortcut Action
Cmd/Ctrl+Shift+P Command palette
Cmd/Ctrl+P Quick open file
Cmd/Ctrl+B Toggle sidebar

Additional Setup (one-time)

After cloning the workspace and running ./scripts/setup, install the extra dependencies:

# TypeScript + self-improvement deps
npm install

# Qdrant (optional, for semantic search)
docker compose up -d
Team rules work without Qdrant

Rules are injected via a lightweight JSON+keyword hook. Qdrant is only needed if you want semantic vector search for memory and context retrieval.

Your First 5 Minutes

Step 1: Add Your Project

Add your existing project (auto-symlinked) or create a new one. Git platform is auto-detected!

# Add existing project (auto-symlinked, git platform auto-detected)
./scripts/add-project ~/code/my-react-app

# Clone from GitHub (auto-detects: github)
./scripts/add-project https://github.com/user/repo

# Clone from Bitbucket (auto-detects: bitbucket + workspace)
./scripts/add-project https://bitbucket.org/mycompany/repo

# Or create new empty project
./scripts/add-project my-new-project

Git config saved to .ai-contexts/<project>.yaml - different projects can use different platforms!

Step 2: Verify Project

./scripts/list-projects

# Output:
📁 my-project
📁 my-react-app
📁 ...

Step 3: Start a Task

Troubleshooting

PROBLEM: "claude: command not found"
npm install -g @anthropic-ai/claude-code
claude --version
PROBLEM: Claude Panel not showing in Cursor
  1. Check: Does .mcp.json exist in workspace root?
  2. Try: Cmd+Shift+P → "Developer: Reload Window"
  3. Check: Is Claude extension enabled?
PROBLEM: "No active session"
/work-ticket "your task description"
PROBLEM: Session state corrupted
rm -rf .ai-session/
/work-ticket "your task"
