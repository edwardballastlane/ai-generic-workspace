Usage Guide

Step-by-step guidance for using the Lane workflow orchestrator

Quick Start

/work-ticket "Your task description here"

That's it. The orchestrator analyzes your task and activates the right workflow.

Prerequisites

⌨ Option A: Claude Code CLI

Node.js v20+
Claude Code CLI Latest
Git Any
npm install -g @anthropic-ai/claude-code

💻 Option B: Cursor IDE

Cursor IDE Latest
Use Cursor Chat
Node.js v20+ (for MCP)

Adding Projects

Before starting work, add your project to the workspace. Git platform is auto-detected!

# Add existing project (symlinked, git platform auto-detected)
./scripts/add-project ~/code/my-react-app

# Clone from GitHub (auto-detects: github)
./scripts/add-project https://github.com/user/repo

# Clone from Bitbucket (auto-detects: bitbucket + workspace)
./scripts/add-project https://bitbucket.org/mycompany/repo

# Clone from GitLab
./scripts/add-project https://gitlab.com/user/repo

# Create new empty project
./scripts/add-project my-new-project

# Verify
./scripts/list-projects
🌐 Per-Project Git Platform: Git platform is auto-detected from remote URL and saved to .ai-contexts/<project>.yaml. Different projects can use different platforms!
💡 Auto-Symlink: Local paths are automatically symlinked - changes sync both ways. Use --copy flag if you need a separate copy.

Core Workflow

Step 1: Start a Workflow

Choose how to begin based on your task:

Entry Point Command Best For
Smart Router /work-ticket "task" Most tasks - AI decides workflow
Bug Fix /work-ticket "fix bug..." Quick fixes (5 min)
Feature /work-ticket "add feature..." New functionality (15 min)
System /work-ticket "build system..." Large projects (30 min)

Step 2: Follow the Agents

The orchestrator activates agents in sequence:

Quick Flow

💻 Developer → 🧪 Tester → 🚀 Deployer

Full BMAD

🏗 Architect → 🎨 Designer → 💻 Developer → 🧪 Tester → 👁 Reviewer → 🚀 Deployer → 📚 Documenter

Enterprise

🔍 Analyst → 📊 Product Owner → 🏗 Architect → 🎨 Designer → 💻 Developer → 🧪 Tester → 👁 Reviewer → 🚀 Deployer
Agent Handoffs are Automatic:
  • Each agent completes their work
  • Handoff summary appears in conversation
  • Next agent activates immediately
  • You just watch and provide input when asked

Step 3: Deliver Output

The workflow ends when:

  1. Deployer creates a PR or deploys code
  2. Documenter finalizes documentation
  3. Session status becomes "completed"

Session State

The orchestrator tracks state in .ai-session/current.yaml:

session:
  id: "20260115-093045"
  workflow: "full-bmad"

task:
  original: "Add dark mode toggle"

current:
  phase: 2
  agent: "architect"
  agent_status: "active"

progress:
  agents_completed:
    - architect

outputs:
  files:
    - "docs/architecture.md"

View current session:

# Terminal
cat .ai-session/current.yaml

# Or use the command
/progress

/progress

/agent developer

# Verify Node.js
node --version # Should be 18+

# Check MCP config exists
cat .mcp.json

# Restart Claude Code
exit
claude
Session State Corrupted
# Reset session
rm -rf .ai-session/
/work-ticket "your task"

Spec-to-Implementation Pipeline

Lane can take you from idea to running code through a structured pipeline:

Command Description
/spec "task" Generate a structured PRD (Product Requirements Document)
/breakdown <spec-file> Create a wave-based implementation plan from a spec
/swarm-implement <plan> Execute the plan with parallel agent teams

Example Flow

# 1. Generate a spec
/spec "Add role-based access control"

# 2. Break it into waves of parallel tasks
/breakdown docs/specs/rbac-spec.md

# 3. Execute with agent swarm
/swarm-implement docs/plans/rbac-plan.md
Structured artifacts: Each stage produces reviewable files (spec, plan) so you can adjust before moving to the next step.

Self-Improvement System

Lane learns from every session and continuously improves through a rule-based system.

Rules auto-injected on every prompt — 58 team rules + personal rules are applied automatically via a lightweight hook. No external services required.
Command Description
npm run self:dashboard Interactive dashboard showing rules, stats, and pending proposals
npm run rules:promote Promote a personal rule to a shared team rule

Script Description

./scripts/wave-planner Task parallelization — groups tasks into concurrent waves
./scripts/fresh-context Combat context rot — regenerates stale cached context
